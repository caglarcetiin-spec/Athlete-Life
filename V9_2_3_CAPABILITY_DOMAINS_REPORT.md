# Athlete Life OS v9.2.3 — Capability Domains

Capability Lab now supports four additional directly-entered performance domains:
- Balance / Control
- Work Capacity
- Mobility
- Endurance

Each domain uses dated records, editable notes, test-specific units, transparent performance bands, history cards, and Athlete Profile domain scoring. Existing running and legacy power tests remain compatible; direct Work Capacity / Endurance records are preferred when present without deleting older evidence.
