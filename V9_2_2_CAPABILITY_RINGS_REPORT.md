# Athlete Life OS v9.2.2 — Capability Lab Muscle-Up + Rings

- Calisthenics Capability selector is now grouped with optgroups.
- Muscle-Up has a dedicated group: strict, explosive, slow/no-kip, weighted bar, strict ring and weighted ring variants.
- Gymnastics Rings coverage expanded: false grip, support/RTO, pulls/rows, dips, L-sit, skin-the-cat, German hang, ring levers, handstand/HSPU, Iron Cross and Maltese.
- Existing capability record format remains backward-compatible (`reps`, `seconds`, `load_reps`).
- Capability cards now display their movement group.
- PWA cache bumped to v9.2.2 so the expanded catalog is not hidden by stale cache.
